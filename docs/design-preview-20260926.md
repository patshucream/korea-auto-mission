# 코리아오토미션 홈페이지 시안 · 2026-09-26

## 최종 사용자 방향

첫 번째 흰색·남색 카드형 시안은 사용자가 거절했다. 별도 AI 에이전트는 원인을 검토했고, 주 에이전트가 두 번째 화면을 직접 재설계했다. 외부 디자인 전용 AI 서비스를 사용한 것은 아니다.

사용자는 두 번째 현장 사진·차콜 화면에 “좋네”라고 답한 뒤 고급스럽고 절제된 애니메이션을 요청했다. 현장·부품·차량 사진과 화면만 따로 고급스럽게 보이면 이질감이 생기니 자연스럽게 섞어 달라고 했다. **전후 비교는 웬만하면 하지 말라**고 명시하여 첫 시안의 비교 배치와 잠시 만든 비교 슬라이더를 모두 제거했다.

## 적용한 구성

- 실제 정비 중인 사진을 첫 화면에 크게 사용. 차콜과 회백색, 금속·현장 사진에 어울리는 차분한 색상.
- 디젤 서비스는 반복되는 세 장의 카드 대신 사진 한 장과 항목 목록. 각 서비스 선택·포커스·제목 호버에 실제 작업 사진이 서서히 전환됨. 모바일은 흡기·인젝터·DPF 이름이 있는 탭과 좌우 사진 넘기기를 제공하고 선택한 서비스 설명만 표시한다.
- 제목이 아래에서 드러나는 첫 등장, 화면에 들어오는 섹션의 한 번만 실행되는 등장, 서비스 선택선, 작은 사진 확대 효과.
- 자동 사진 회전·스크롤 가로채기·전후 비교·반복 점멸 없음. 모션 감소 설정에서는 애니메이션과 전환을 제거한다. JavaScript 미실행 시 본문은 기본적으로 표시된다.
- 정비 과정은 SM5 DPF 실제 작업 사진과 원칙, 사례는 크기가 다른 편집형 배치. 가격·결과·후기를 임의 생성하지 않음.
- 모바일 전화·문자 고정 메뉴, 원본 파란 Kauto 로고 유지.

사용자가 모바일 비중을 강조하고, 디젤만 강조해 미션수리가 빠져 보인다며 전기차 감속기 수리도 포함하도록 요청했다.

- 첫 화면·메뉴·증상 바로가기에 디젤클리닝, 미션수리, 전기차 감속기 정비를 함께 표시한다.
- 서비스 영역 첫머리에 세 분야 바로가기를 제공한다. 미션수리를 실제 BMW 325CI 변속기 분해 작업 사진과 설명이 있는 독립 영역으로 확대했다.

- 모바일 본문 크기·행간·여백을 키우고, 서비스 설명을 짧게 선택해 읽도록 정리했다. 하단 전화·문자 버튼은 아이콘과 보조 문구를 갖춘 차콜색 고정 바로가기로 변경했다.
