# 홈페이지 리뉴얼 — 2026-09-16

`korea-auto-mission-final` 원본을 바탕으로 작업한 리뉴얼입니다. 검토한 화면을 기존 GitHub → Vercel 배포 방식으로 운영 사이트에 반영합니다. 블로그 작업사례 이전은 `blog-import.md`에 기록했습니다.

## 변경 사항

- 차콜·아이보리·구리색 포인트, 사진과 문구를 나눈 메인 화면.
- 실제 공개 작업사례를 크게 보여주는 구성과 펼쳐 보는 정비 서비스.
- PC·태블릿·휴대폰에 맞는 메뉴 및 모바일 전화·예약 버튼.
- 비어 있는 홈페이지 후기/작업사례 영역과 서비스별 0건 표시 제거.
- 등록된 사례의 브랜드만 안내하고, 실제 연결 가능한 메뉴만 표시.
- 영업시간과 매장 사진, 외부 지도 바로가기로 방문 정보 정리.

## 기존 관리 기능과의 연결

관리자 설정의 첫 화면 문구와 이미지, 정비 철학, 서비스, 공개 작업사례, FAQ, 영업시간, 연락처, 예약 주소를 그대로 읽습니다. 홈페이지 섹션 순서·노출 설정과 대표 서비스·사례 선택도 유지합니다. 고객후기는 공개된 내용이 있을 때 홈페이지에 나타나며, 별도 후기 페이지와 작성 기능은 유지됩니다.

주요 구현은 `src/components/home/PremiumHome.tsx`와 `PremiumHome.module.css`에 있습니다. 메뉴·푸터·모바일 상담 버튼은 기존 공개 페이지에서도 공유합니다. 이 스타일은 CSS Module로 한정되어 관리자 화면의 디자인에 영향을 주지 않습니다.

기존 사이트맵의 구버전 데이터 조회 타입 오류와 관리자 작성 폼의 렌더링 중 ref 갱신 오류도 수정했습니다.

## 확인

- TypeScript 검사 및 ESLint 오류 검사 통과.
- Next.js 운영 빌드 통과.
- 320px / 390px / 820px와 기본 데스크톱 화면에서 가로 넘침 점검.
- 모바일 메뉴 열기·섹션 이동·자동 닫힘, 서비스 펼침, FAQ 펼침 확인.
- 실제 작업사례 상세 화면 연결, 홈페이지 앵커, 연락처·예약 링크 확인.

## 실행

개발: `npm run dev -- --hostname 127.0.0.1 --port 3088`

운영 방식으로 미리 보기: `npm run build` 후 `npm start -- --hostname 127.0.0.1 --port 3089`

운영 환경에는 `BLOG_IMPORT_PREVIEW`를 설정하지 않습니다. 공개 작업사례는 운영 데이터베이스에서 조회합니다.
